## ✨ 核心特性

1. **📱 专为手机与移动端优化的沉浸阅读体验**
   - 响应式自适应布局，手机端提供底部触控栏（目录、搜索、视图切换、一键回顶）。
   - 侧边抽屉式目录（TOC），涵盖全书 11 个章节与 190 个节级标题，点击即刻丝滑跳转。
   - 顶部阅读进度指示条与当前章节实时徽章跟随。

2. **🌓 三大舒适阅读主题与字号调节**
   - **浅色模式（默认）**：清新纸墨质感。
   - **羊皮纸模式（Sepia）**：温润护眼色调，适合弱光或长时间阅读。
   - **深色模式（Dark）**：OLED 纯黑暗色，夜间阅读更舒适。
   - 支持动态字号放大与缩小（A- / A+）。

3. **🔍 全书 27 万字毫秒级全文实时检索**
   - 提取全书 306 页无损文本流，支持实时快速搜索。
   - 智能高亮搜索关键词，展示上下文预览摘要，点击一键跳转对应页码。

4. **🖼️ 三大视图随意切换**
   - **高清图文流（HD Visual Stream）**：原书排版高精度渲染（WebP 格式，保留所有数学公式、矢量图表、曲线与拓扑结构），支持懒加载与平滑翻页。
   - **纯文本图文排版（Text Flow & Formulas）**：重组自然段落流，内嵌全书 **195 幅高清插图**与 **128 个独立高精数学公式卡片**（支持灯箱点击放大），适合小屏幕手机流式阅读。
   - **PaddleOCR 智能识别比对（PP-OCRv6 Showcase）**：集成百度最新发布的 **PaddleOCR 3.x (PP-OCRv6)** 模型，可视化呈现文字检测框（Detection Polygons）、识别文本与置信度。

5. **📐 目录隐藏/展开与沉浸式阅读交互**
   - 桌面端支持一键隐藏左侧目录侧边栏，正文自适应扩展为 100% 全宽沉浸式排版；折叠时左侧边缘提供半透明悬浮把手（Edge Trigger），随时一键唤出。
   - 移动端提供底部轻触抽屉式目录，支持半透明遮罩背景轻触与 ESC 快捷键收起。
   - 彻底过滤页眉页脚（`·8· 涡街流量计...`）噪音，章节标题层级化高亮显示。

6. **🤖 百度最新 PaddleOCR (PP-OCRv6) 验证集成**
   - 采用 `PP-OCRv6_medium_det` 检测模型与 `PP-OCRv6_medium_rec` 识别模型。
   - 包含样页实机检测识别数据 `data/ocr_samples.json`，提供置信度分析与推理耗时基准。

## 💻 本地离线运行

无需任何编译或后端服务，直接使用任意本地 Web 服务器即可：

```bash
# Python 3
cd vortex-flowmeter-dsp
python -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080` 即可离线阅读。

## 🛠️ 数据生成与提取脚本

- `scripts/export_all_pages.py`: 提取 PDF 矢量文字流与高清 WebP 页面。
- `scripts/parse_toc.py`: 解析原书目录并构建结构化 TOC JSON。
- `scripts/extract_all_formulas.py`: 提取全书 128 个独立公式高精度裁剪图 (formulas/*.webp)。
- `scripts/process_all_formulas_ocr.py`: 使用 PaddleOCR PP-OCRv6 对全书 128 个数学公式进行批量 OCR 识别与结构化提取，生成 `data/formulas.json`。
- `scripts/run_sample_ocr.py`: 调用 PaddleOCR PP-OCRv6 进行样页检测识别并输出置信度。
